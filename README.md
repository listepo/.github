# .github

Default community health files for [listepo](https://github.com/listepo) repositories.

GitHub applies the files here (issue templates, pull request template) to every public
repository under `listepo` that doesn't define its own. A repository's own `.github/`
files always take precedence over these defaults.

- `.github/ISSUE_TEMPLATE/` - bug report and feature request forms
- `.github/pull_request_template.md` - default pull request template
